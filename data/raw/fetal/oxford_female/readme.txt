This dataset contains accelerometer-recorded fetal movement signals with 16 different pregnant women
The dataset contains signals from one accelerometer placed on the abdominal wall of the pregnant women.

Note:
The file format is .mat, which is recognized by the Matlab software. 
the "xxxxxx_bp" files contain the signals of the maternal perception markers, and the "xxxxxx_signal" files contain acceleration data from the 3 axes (x, y, and z).
Hardware settings: 
accelerometer: ADXL355 from ANALOG DEVICES
Sampling frequency: 500Hz
